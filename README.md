# Morphogrammer Extension

Браузерное расширение для транслитерации кириллического текста в другие письменности: латиницу, греческий, иврит, цифры и Unicode-символы.

Расширение создано на основе проекта [Morphogrammer](https://github.com/tzaralexrex/Morphogrammer). Можете использовать страницу настроек в качестве независимого перекодировщика.

## Возможности

- **Гибкая настройка соответствий** — для каждой кириллической буквы можно задать замены по пяти направлениям (латиница, греческий, иврит, цифры, Unicode)
- **Приоритет замен** — выбирайте, какие столбцы использовать при преобразовании (Unicode → Цифры → Иврит → Греческий → Латиница). Если символ в столбце Unicode совпадает с исходным, автоматически используются замены из других столбцов
- **Таблица выбора Unicode-символов** — встроенный пикер для удобного выбора символов из всех блоков Unicode
- **Мгновенное применение** — изменения сохраняются автоматически
- **Предпросмотр** — тестируйте настройки на примере перед использованием
- **Экспорт/импорт настроек** — делитесь пресетами или делайте бэкапы
- **Горячие клавиши** — быстрая транслитерация выделенного текста в любом месте браузера
- **Контекстное меню** — альтернативный способ преобразования через правый клик
- **Поддержка contenteditable** — работает в текстовых полях, textarea и редактируемых блоках

## Установка

### 1. Скачайте расширение (для установки вручную)

- Клонируйте репозиторий:
  ```bash
  git clone https://github.com/tzaralexrex/Morphogrammer-Extension.git
  ```
- Или скачайте ZIP-архив через кнопку **Code → Download ZIP** и распакуйте.

### 2. Загрузите в браузер

#### Google Chrome и браузеры на Chromium (Edge, Brave, Opera и др.)

Найдите дополнение по имени **Morphogrammer** в магазине дополнений (https://chromewebstore.google.com/detail/dhkfacfpkjglpkmdkedfpdpnnmcljnfl) и установите оттуда.

1. Откройте `chrome://extensions/` (или `edge://extensions/`, `brave://extensions/` и т.д.)
2. Включите **Режим разработчика** (переключатель в правом верхнем углу)
3. Нажмите **Загрузить распакованное расширение**
4. Выберите папку с расширением (ту, где находится `manifest.json`)
5. Расширение появится в списке

> **Примечание**: при загрузке в Chrome может появиться предупреждение: `"'background.scripts' requires manifest version of 2 or lower."` — это ожидаемое предупреждение из-за кросс-браузерной совместимости с Firefox. Расширение работает корректно, предупреждение можно игнорировать.

#### Mozilla Firefox

Найдите дополнение по имени **Morphogrammer** в магазине дополнений (https://addons.mozilla.org/ru/firefox/addon/morphogrammer/) и установите оттуда.

Либо установите как временное дополнение из исходного кода:

1. Откройте Firefox и перейдите на `about:debugging`
2. В левой панели выберите **Этот Firefox** (This Firefox)
3. Нажмите **Загрузить временное дополнение…** (Load Temporary Add-On)
4. Выберите файл `manifest.json` из папки с расширением
5. Расширение появится в списке

> **Важно для Firefox**: временное дополнение загружается только до перезапуска браузера. После закрытия Firefox его нужно загрузить заново через `about:debugging`. Для постоянной установки потребуется подписка расширения через [Firefox Add-ons Developer Hub](https://addons.mozilla.org/developers/).
>
> В Firefox расширение не работает на локальных файлах (`file://`). Для тестирования используйте локальный сервер или открывайте страницы через `http://` / `https://`.

### 3. Настройте горячие клавиши

#### Chrome и браузеры на Chromium

1. Перейдите на `chrome://extensions/shortcuts` (или аналогичный URL в вашем браузере)
2. Найдите **Morphogrammer** в списке
3. Кликните на иконку редактирования справа от поля с комбинацией и нажмите удобную вам (по умолчанию `Alt+Shift+M`)

#### Firefox

1. Откройте `about:addons`
2. Нажмите на шестерёнку в правом верхнем углу → **Управление дополнениями** (Manage Extensions)
3. Найдите **Morphogrammer** в списке
4. Нажмите на шестерёнку рядом с расширением → **Изменить комбинацию клавиш** (Edit Keyboard Shortcuts)
5. Назначьте удобную комбинацию (по умолчанию `Alt+Shift+M`)

## Использование

### Быстрое преобразование

**Способ 1: Горячие клавиши**
1. Выделите текст на любой веб-странице
2. Нажмите горячую клавишу (например, `Alt+Shift+M`)
3. Выделенный текст будет заменён на транслитерированный

**Способ 2: Контекстное меню**
1. Выделите текст на любой веб-странице
2. Кликните правой кнопкой мыши
3. Выберите **Преобразовать выделенное (Morphogrammer)**

**Способ 3: Кнопка на панели расширений**
1. Выделите текст на любой веб-странице
2. Кликните на иконке расширения на панели (не забудьте заранее её там закрепить)
3. Выберите **Преобразовать**

> **Примечание для Firefox**: кнопка в popup может не активироваться на некоторых сайтах, где выделение снимается при потере фокуса (например, строка поиска Google). Это ограничение браузера. Используйте горячие клавиши или контекстное меню — они работают стабильно на всех сайтах.

### Настройка соответствий

1. Откройте настройки расширения:
   - **Chrome**: `chrome://extensions/` → кнопка **Сведения** → **Параметры расширений**
   - **Firefox**: `about:addons` → Morphogrammer → **Параметры** (или через значок расширения → «Настройка таблиц»)
2. В таблице настройте замены для каждой буквы:
   - Используйте выпадающее меню для быстрого выбора из предустановленных символов
   - Или введите символы вручную (можно несколько, например `ы → bl`)
   - Для Unicode-символов нажмите кнопку **⋯** справа от поля — откроется таблица выбора символов Unicode с поиском по коду (например, `U+03B1`) и названию блока
3. Включите/выключите чекбоксы приоритетов сверху:
   - **Unicode** — замена на символы из столбца Unicode (если символ совпадает с исходным, используются другие столбцы)
   - **Цифры** — замена на цифры
   - **Иврит** — замена на ивритские символы
   - **Греческий** — замена на греческие символы
   - **Латиница** — замена на латинские символы
4. Проверьте результат в поле **Пример**
5. Настройки сохраняются автоматически

### Экспорт и импорт настроек

- **Экспорт JSON** — сохраните текущие настройки в файл для бэкапа или переноса
- **Импорт JSON** — загрузите настройки из файла (например, из бэкапа или пресета)

## Известные ограничения

- **Firefox (временный режим)**: расширение загружается как временное дополнение и работает только до перезапуска браузера. Для постоянной установки требуется подписка через [Firefox Add-ons Developer Hub](https://addons.mozilla.org/developers/).
- **Firefox (popup)**: кнопка в popup может не активироваться на некоторых сайтах, где выделение снимается при потере фокуса (например, строка поиска Google). Используйте горячие клавиши или контекстное меню — они работают стабильно на всех сайтах.
- **Firefox (локальные файлы)**: расширение не работает на локальных файлах (`file://`). Используйте локальный сервер (например, `http://localhost:8000`) или открывайте страницы через `http://` / `https://`. В Chrome работа с `file://` поддерживается.
- **Вложенные contenteditable**: при выделении текста, пересекающего несколько редактируемых блоков (включая `contenteditable="false"`), трансформация может применяться ко всему выделению. Это редкий кейс, доработка запланирована.
- **Shadow DOM и iframe**: трансформация не работает внутри Shadow DOM и iframe с другим origin. Это ограничение безопасности браузеров.
