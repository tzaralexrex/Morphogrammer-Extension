Политика конфиденциальности Morphogrammer

Дата вступления в силу: 22 сентября 2026 г.

1. Общие сведения

Morphogrammer — браузерное расширение для локального преобразования выделенного кириллического текста по пользовательской таблице замен. Расширение может применять замены на латиницу, греческие и еврейские символы, цифры и другие символы Unicode.

2. Какие данные обрабатывает расширение

Расширение может локально обрабатывать выделенный пользователем текст в поддерживаемых редактируемых элементах веб-страницы: текстовых полях input, textarea и блоках contenteditable. Такой текст используется исключительно для выполнения преобразования, явно запрошенного пользователем через горячую клавишу, пункт контекстного меню или интерфейс расширения.

Расширение также хранит локально пользовательские настройки: таблицу соответствий символов и выбранные приоритеты преобразования. Эти настройки сохраняются в хранилище браузера chrome.storage.local, чтобы оставаться доступными между сеансами браузера.

При импорте настроек расширение читает только JSON-файл, который пользователь самостоятельно выбрал на своём устройстве. При экспорте расширение создаёт локальный JSON-файл с пользовательской таблицей настроек.

3. Как используются данные

Выделенный текст используется только для локального преобразования и вставки результата обратно в тот же редактируемый элемент. Выделенный текст не сохраняется в chrome.storage.local, не используется для рекламы, аналитики, профилирования или иных несвязанных целей.

Пользовательская таблица замен и настройки приоритетов используются только для настройки и выполнения функции преобразования текста.

4. Передача и раскрытие данных

Morphogrammer не передаёт пользовательские данные на серверы разработчика, третьим лицам или рекламным сетям. Расширение не использует внешние API, аналитику, рекламу, трекеры, сетевые запросы или удалённые сервисы для обработки текста.

Расширение не продаёт и не передаёт пользовательские данные для персонализированной рекламы, ретаргетинга, профилирования, оценки кредитоспособности или иных целей, не связанных с основной функцией расширения.

5. Доступ к веб-страницам

Для работы функции преобразования content script расширения может работать на открываемых пользователем веб-страницах. Он взаимодействует с поддерживаемыми редактируемыми элементами, чтобы сохранить текущее выделение и по явной команде пользователя заменить выделенный фрагмент преобразованным текстом.

Расширение не собирает историю посещений, не сохраняет URL веб-страниц, не передаёт содержимое страниц и не использует данные страниц для рекламы, аналитики или профилирования.

6. Пароли и учётные данные

Morphogrammer не предназначен для работы с полями паролей и не обрабатывает текст в input type="password". Расширение не получает, не сохраняет и не передаёт пароли, файлы cookie, токены аутентификации или другие учётные данные.

7. Удалённый код

Расширение не загружает и не выполняет удалённый код. Все JavaScript, HTML, CSS и локальные модули входят в пакет расширения.

8. Хранение и контроль данных

Настройки расширения хранятся локально в профиле браузера через chrome.storage.local. Пользователь может изменить или сбросить настройки на странице настроек расширения, удалить расширение или очистить данные расширения средствами браузера.

9. Изменения политики

Эта политика может обновляться при изменении функций расширения. Актуальная версия всегда публикуется по адресу этой страницы.

10. Контакты

По вопросам о конфиденциальности и работе расширения можно обратиться к разработчику через страницу репозитория: https://github.com/tzaralexrex/Morphogrammer-Extension .
