Morphogrammer — Таблица соответствий

Настройте замены для каждой кириллической буквы по пяти направлениям: латиница, греческий, иврит, цифры, Unicode.
Чекбоксы ниже определяют, какие столбцы используются при преобразовании. Приоритет замены растёт слева направо.

Пример

Таблица соответствий

Выберите кириллическую букву в первом столбце — остальные столбцы покажут текущие соответствия.
Измените любой столбец — соответствие обновится для выбранной буквы.

Кириллица Латиница Греческий Иврит Цифры Unicode Сброс

Инструкция

  • В столбце «Кириллица» найдите букву для настройки.
  • В остальных столбцах укажите соответствующие символы.
  • Оставьте поле пустым (-), если замена не нужна.
  • Можно вводить несколько символов (например, «ы» → «bl»).
  • Строка подсвечивается более тёмным цветом, если для буквы нет ни одной замены.
  • Чекбоксы выше определяют приоритет: Unicode → Цифры → Иврит → Греческий → Латиница.
  • Любые изменения сохраняются сразу автоматически.
  • «Экспорт JSON» — сохраните текущие настройки в файл для бэкапа или переноса.
  • «Импорт JSON» — загрузите настройки из файла (например, из бэкапа или пресета).

Горячие клавиши

Для быстрого преобразования выделенного текста используйте комбинацию Alt+Shift+M.

Чтобы изменить горячую клавишу:

  1. Откройте настройки горячих клавиш браузера.
  2. Найдите Morphogrammer в списке.
  3. Кликните на иконку редактирования справа от поля с комбинацией и нажмите новую.
